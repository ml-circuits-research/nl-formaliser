nl-formaliser — Formalizator Simbolic NL → SOP Lang în Z3

nl-formaliser traduce cereri exprimate în limbaj natural în circuite SOP Lang (w.request) validate formal împotriva lumilor din sop-knowledge-worlds. Principiul central al proiectului este că toată logica de dezambiguizare semantică stă declarativ în Z3 (SMT-LIB2 MaxSMT), iar Node.js (.mjs) acționează doar ca wrapper subțire pentru încărcarea cunoștințelor, construirea laticei lexicale nefiltrate, invocarea Z3 și verificarea ieșirii.

Ce este SOP Lang (w.request)? Este o reprezentare canonică, deterministă și verificabilă de tip „wire circuit” pentru intenții (w.request.request, target, constraint, lookup, filler, unread). Un circuit valid garantează prin construcție: (1) fiecare cheie și valoare aparține schemei lumii active, (2) orice țintă existentă neidentificată declară explicit un lookup, (3) orice frază emisă este ancorată exact (grounded) în textul sursă, și (4) ceea ce nu poate fi formalizat corect este izolat onest în unread.

Pornire rapidă (CLI & API)

# 1. Rulare suită completă de teste (57 teste: KB dinamic SOP, latice, spellchecker Z3, Z3 ierarhic, confidence, verifier, E2E)
npm test

# 2. Spellchecker Z3 standalone (Layer 1, independent de formalizator)
npm run test:spell
node bin/spellcheck.mjs --top 2 "the losing months should stando ut, so make theb ars below 7 teal"

# 3. Formalizare din linia de comandă (Layer 2 + opțional --spellcheck și --confidence)
node bin/formalise.mjs --tab drawing "make the house blue" --verify --confidence
node bin/formalise.mjs --tab drawing "copy the atble" --spellcheck --verify --confidence
node bin/formalise.mjs --tab diagram "make a bar chart of the stadiums by country" --top 3 --verify --confidence

# 4. Calibrare & Benchmark paralel pe 10 workeri Z3
node eval/calibrate.mjs
node eval/benchmark.mjs --source webmeet --sample-pct 1 --seed 42 --workers 10 --spellcheck --confidence
node eval/benchmark.mjs --source test --limit 500 --seed 42 --workers 10 --spellcheck --confidence
node eval/benchmark.mjs --source keys --workers 10

Exemplu programatic (Node.js ESM)

import { createFormaliser } from './src/index.mjs';

const formaliser = await createFormaliser({ timeoutMs: 4000 });
const res = await formaliser.formalise('move the house to 260,180, then make the house blue', {
  tab: 'drawing',
  topK: 2,
  verify: true,
});
console.log(res.sop);         // Circuit SOP Lang valid (100% verificat)
console.log(res.alternatives); // Interpretări alternative clasate de Z3
